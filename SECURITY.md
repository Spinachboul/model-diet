# Security policy

Please report suspected security vulnerabilities privately. Do not include exploit details, credentials, or unpatched vulnerability information in a public issue.

Use GitHub's **Report a vulnerability** option in the repository's Security tab if private vulnerability reporting is enabled. If that option is unavailable, contact the repository maintainers privately through GitHub and ask for a private reporting channel; do not publish the report in an issue or pull request.

Include the affected Model Diet version or revision, the dependency or component involved, the impact you observed, and steps to reproduce where it is safe to do so. Avoid sending secrets or personal data.

There is no security contact email configured for this project.
