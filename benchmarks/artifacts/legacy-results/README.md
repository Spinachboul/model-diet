# Legacy benchmark records

These raw-run and summary JSON files were moved out of `src/modeldiet/results/` so benchmark outputs are not shipped as Python package contents. The 30 raw files are grouped by the `lr`, `rf`, and `xgb` filename prefixes, with one summary per model.

The records are preserved byte-for-byte. Their original run date, source revision, dependency versions, hardware, and full benchmark configuration were not recorded, so they are retained as historical repository artifacts only. Do not use them as reproducible or directly comparable performance claims.
